About

Overview

This web app turns spreadsheets into flashcards. Make a spreadsheet with columns for the "front" and "back" of your cards either as an Airtable or a CSV file, then connect/upload it under Settings. If you have a keyboard, you can press Space to flip a card, ↑ for Knew It, or ↓ for Didn't Know It. You can find more context and instructions in the README file for this project's GitHub repo.
